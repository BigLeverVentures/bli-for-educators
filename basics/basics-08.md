# 08 — Set Up a Project for Continuing Work

[Curriculum](../curriculum.md) · [Teaching-use license; no resale](../LICENSE.md) · Alpha release · [Evidence and limits](../educators/evaluation.md)

<p><em>Project guide: separate sources, instructions and chats; keep approved learning and check retrieval in a fresh conversation.</em></p>
<p>A <strong>Project</strong> groups continuing work, usually with conversations, source material and instructions. Use one when you return to the same topic; a single invitation does not need one. Saving files, instructions and conversations are different actions. Do not assume every new chat knows what happened in another.</p>
<h2>A small workspace you can test</h2>
<p>Use these fictional source notes; copy only this block into the source/context area when the route below asks for notes.</p>
<h3>Source notes — separate from instructions</h3>
<p><strong>Copy this prompt</strong></p>
<blockquote><p>Workshop notes</p>
<p>Day: Tuesday</p>
<p>Time: 3 p.m.</p>
<p>Place: Room A</p>
<p>Bring: a notebook</p>
<p>End time: not provided</p>
</blockquote>
<p>Read only the route for the service you chose. Name your workspace “Workshop practice.” Keep it private; you do not need to share it with BLI.</p>
<h3>ChatGPT web</h3>
<ol><li>open the sidebar → New project → name it.</li>
<li>Add the notes as pasted text or an available source/file.</li>
<li>Open the Project&#x27;s ••• menu → Project settings to add the instructions below.</li>
<li>Start your practice chat inside that Project.</li>
</ol>
<h3>Claude web</h3>
<ol><li>open Projects → new-project control → name it.</li>
<li>In the Project&#x27;s Context/knowledge area, use +/Add files → text-content option to paste the notes, or upload a permitted file.</li>
<li>In Instructions, use the edit/set control, paste the instructions and save.</li>
<li>Start the chat from the Project page.</li>
<li>The name alone is not your source context.</li>
</ol>
<h3>Gemini web, if Notebooks is available</h3>
<ol><li>sidebar → Notebooks → New notebook; name it and begin a chat.</li>
<li>Use Add sources for the source notes.</li>
<li>To save instructions: All notebooks → open this notebook → More → Notebook settings → instructions → Save.</li>
<li>Gemini Notebook must be connected; review any connection request before deciding.</li>
<li>Rollout and account access vary.</li>
<li>Keep Activity affects saved chats and use of past conversations; do not change privacy settings just to complete this lesson.</li>
<li>Use the pasted-context fallback below if the feature is missing or you prefer it.</li>
</ol>
<p>If you cannot access one of those features, keep your instructions and notes in your own plain text note. Paste both into a new chat when you resume. It takes an extra step and does not promise automatic memory.</p>
<h2>Add the instructions and the facts separately</h2>
<p>Copy this block into the workspace&#x27;s instructions field, or the beginning of your fallback chat. The workshop notes belong in source context, not in these general instructions.</p>
<h3>Workspace instructions</h3>
<p><strong>Copy this prompt</strong></p>
<blockquote><p>Help me organize the workshop using the notes I provide. Use plain language. Distinguish a supplied fact from a suggestion. Ask me about missing details that matter. Do not invent dates, locations, commitments or approvals. When I request a draft, make it here; do not send or publish anything.</p>
<p>Challenge important unsupported details and let me choose corrections.</p>
</blockquote>
<p>For the fallback chat, paste the source-notes block above after these instructions. For a Project or notebook, add those notes to its source/context area. For a notebook, add the notes as source text using the available source control. If that control cannot accept your notes, use the pasted-context fallback.</p>
<h2>Check what it retained</h2>
<p>Start a fresh conversation inside the saved workspace and ask: “From the workshop notes you can read, when and where is it, what should attendees bring, and is the end time known?” Do not repeat the answers in that test question.</p>
<p>Compare with your saved source: Tuesday, 3 p.m., Room A, notebook, end time unknown. If it cannot read the notes or adds a time, fix the source placement or ask for a correction and repeat the check. In the pasted-context fallback, supply the notes each time; you are checking whether it can read the notes now, not whether it remembers them later.</p>
<p>At a useful stopping point, save an approved decision or summary explicitly as source text or in your own note. Reopen it later and check it. Do not rely on “remember this” as proof of a saved copy you can reopen.</p>
