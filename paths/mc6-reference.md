# Prompting and Workflows — Reference at the Point of Need

[Curriculum](../curriculum.md) · Alpha release · [Evidence and limits](../educators/evaluation.md)

<h2>Concepts when you need them</h2>
<p>A reusable workflow includes its task, inputs, method, output and checks. A prompt without context can hide assumptions. A baseline is the natural question you would otherwise ask with the same information and capabilities. Compare useful outcomes, not length or elaborate roles. Role-play can expose a perspective but is not independent expert review.</p>
<h2>A worked distinction</h2>
<p>Example: a template worked for a familiar client because the conversation already held their constraints. In a fresh chat it becomes generic. Add explicit input slots for the constraints and test again; do not assume the assistant remembered them.</p>
<h2>Return to the work</h2>
<p>Use the concept to make a concrete check or decision in your current artifact. If it does not help, return to the task rather than collecting terminology. Ask your assistant to explain an unfamiliar term using your example, then check the explanation against the source or observed behavior.</p>
