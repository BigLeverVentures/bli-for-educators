# Product Thinking — Connected Exercise Path

[Curriculum](../curriculum.md) · [Teaching-use license; no resale](../LICENSE.md) · Alpha release · [Evidence and limits](../educators/evaluation.md)

<h2>Begin with evidence and a useful result</h2>
<p>Use Stakeholder Map and User Stories with real workflow notes, or explicitly labeled hypotheses when evidence is not yet available. Distinguish the people using, buying, paying for and operating the product. Choose a small useful outcome and observable acceptance checks before turning the scope into a roadmap.</p>
<p>For help supplying readable workflow notes, see <a href="../basics/basics-06.md">Give AI Text or a File to Work From</a>.</p>
<h2>Carry the work into the next step</h2>
<p>Carry approved needs, evidence, constraints and dependencies into Roadmap Builder. Compare a few candidates, keep unknown effort and benefit explicit, and choose a feasible first item. Inspect what would change the order. If stories lack evidence or a dependency blocks delivery, return to the source work rather than cover the gap with a score.</p>
<h2>Use only the support you need</h2>
<p>Decision Matrix can support a genuine comparison, and Decision Record can preserve a consequential choice. Finance Analyzer fits a real personal-spending question; it is not a startup forecast or substitute for product economics. None is mandatory preparation for this path.</p>
