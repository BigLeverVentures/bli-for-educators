# AI Tools and Workflows — Connected Exercise Path

[Curriculum](../curriculum.md) · Alpha release · [Evidence and limits](../educators/evaluation.md)

<h2>Begin with evidence and a useful result</h2>
<p>Choose Project Brain for a topic you will study repeatedly, OR Industry Researcher for a bounded question. Do not do both just to complete the path. Provide readable source material and check which sources the assistant can access. If browsing is unavailable, gather current sources yourself; a stored URL alone is insufficient.</p>
<p>For readable-source help, see <a href="../basics/basics-06.md">Give AI Text or a File to Work From</a>. For continuing work only, <a href="../basics/basics-08.md">Set Up a Project for Continuing Work</a> explains the workspace and pasted-context routes.</p>
<h2>Carry the work into the next step</h2>
<p>Carry the source-grounded understanding into Executive Briefing. State the audience, decision or question, and the evidence they need. Inspect factual claims against the original sources, preserve important disagreement, and make remaining uncertainty usable. Do not treat several summaries repeating the same underlying claim as independent corroboration.</p>
<h2>Use only the support you need</h2>
<p>Use Presentation from Notes only when a deck helps this audience. Keep source references in the exported artifact and inspect the actual file. A text outline remains a useful fallback when export is unavailable, but it is not a finished slide deck.</p>
