# Prompting and Workflows — Overview and Exercise Path

[Curriculum](../curriculum.md) · Alpha release · [Evidence and limits](../educators/evaluation.md)

<p><strong>This is a learning path.</strong> It connects exercises stored in the Exercise Library. Follow the links to do the work, or choose one exercise directly. You do not need to complete every page.</p>
<p>Return here after completing and inspecting useful work. Preserve a method only if it helps you repeat that work; a prompt collection is not the goal.</p>
<p>For your first prompts or guided conversation, use <a href="../basics/basics-04.md">Ask for What You Want</a> or <a href="../basics/basics-05.md">Work Through a Problem with AI</a>. This path is optional continuing practice, not preparation required for other lessons.</p>
<h2>Choose the guidance you need</h2>
<ul><li><a href="mc6-path.md">Connected Exercise Path</a> — the useful sequence, exercise links and checks between steps.</li>
<li><a href="mc6-transfer.md">Transfer and Optional Reflection</a> — try the method on a changed case when that helps.</li>
<li><a href="mc6-reference.md">Reference at the Point of Need</a> — a worked distinction to use if you get stuck.</li>
</ul>
<p>Choose the parts that serve your task. Keep private work with you; these lessons are available for community testing.</p>
