# Coding for Shippers — Overview and Exercise Path

[Curriculum](../curriculum.md) · Alpha release · [Evidence and limits](../educators/evaluation.md)

<p><strong>This is a learning path.</strong> It connects exercises stored in the Exercise Library. Follow the links to do the work, or choose one exercise directly. You do not need to complete every page.</p>
<p>Choose a small tool or software change worth making. Keep a working version, test actual behavior and prepare a focused change for review.</p>
<h2>Choose the guidance you need</h2>
<ul><li><a href="mc5-path.md">Connected Exercise Path</a> — the useful sequence, exercise links and checks between steps.</li>
<li><a href="mc5-transfer.md">Transfer and Optional Reflection</a> — try the method on a changed case when that helps.</li>
<li><a href="mc5-reference.md">Reference at the Point of Need</a> — a worked distinction to use if you get stuck.</li>
</ul>
<p>Choose the parts that serve your task. Keep private work with you; these lessons are available for community testing.</p>
