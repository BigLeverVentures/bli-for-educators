# Prompting and Workflows — Connected Exercise Path

[Curriculum](../curriculum.md) · [Teaching-use license; no resale](../LICENSE.md) · Alpha release · [Evidence and limits](../educators/evaluation.md)

<h2>Begin with evidence and a useful result</h2>
<p>Begin with a task you have already completed and inspected, ideally from another exercise. If you have no successful example yet, finish one useful task first. Use Workflow Library Builder to extract the working instructions, required context, output checks and known limits. Do not build a speculative prompt collection just to fill a library.</p>
<h2>Keep the method with a successful example</h2>
<p>Keep the instructions, required context and meaningful output checks together. Preserve the working version; label changes you have not tried. Use the transfer page when you want to test a new case.</p>
<p>For instruction scope and its difference from changing source facts, see <a href="../basics/basics-07.md">Tell the Assistant How to Help You</a>. A library entry is not automatically an account-wide instruction.</p>
<h2>Use only the support you need</h2>
<p>Decision Record is useful when the work includes a consequential choice you may revisit. Board of Advisors can challenge a developed decision through several perspectives; it does not supply real experts or create evidence. Negotiation Simulator is separate interactive practice when a negotiation is your task. These options are not a mandatory chain.</p>
