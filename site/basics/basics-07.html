07 — Tell the Assistant How to Help You

Instructions tell the assistant how to work. Context gives it relevant information. “Use short sentences” is an instruction. “The event is Tuesday” is a fact. Both can go in a message, but they do different jobs.

Try an instruction in this chat first

Copy this block into a new chat and send it. There are no fields to replace.

Try a response preference

Copy this prompt

For this conversation, explain unfamiliar words in plain language and give one concrete example. Keep your first answer brief; I can ask for more.

Explain what context means when I am using an AI assistant.

Did the answer explain “context” and give an example? If it used confusing words, reply: “Explain that using the workshop notes from lesson 06: Tuesday, 3 p.m., Room A, bring a notebook.” Choose what helped. A preference is a request, not a guarantee of compliance.

Three scopes

  • Message/chat instructions: apply to this conversation as context permits.
  • Project instructions: help guide work inside that particular workspace.
  • Account-wide custom instructions/preferences: can affect other work too. Use them for stable preferences, not one project's dates or facts.

You can keep using chat instructions; changing your account settings is optional.

Where saved instructions live

Read only the route for the service you chose. If you have no saved workspace yet, keep using the chat instructions for now; lesson 08 walks you through creating that workspace. Account-wide settings are optional and do not have identical names or behavior in every app.

ChatGPT

profile/settings → Personalization → Custom Instructions for broad preferences; a Project's settings for that Project's instructions.

Claude

a Project's Instructions area has a control to edit/save them.

Gemini

for continuing work, use a notebook’s instructions; lesson 08 gives the route. Gems and the newer Skills save reusable task instructions. These are different from a continuing notebook.

If Gemini’s controls differ: Google announced personal-account Gems will be replaced by Skills starting November 2026; account availability differs. Follow the official Gemini transition guide if your controls differ. You can always keep the wording in a note and paste it into a chat.

Before saving, read the scope of the setting. Keep a copy of useful wording so you can remove or replace it later. Do not put private facts into a global preference. If you cannot find the saved-instruction feature, paste your preferred instructions at the start of the relevant chat instead.

Check: start a conversation in the place you configured and ask a simple question. Does it follow the preference? If not, clarify the request or check where you saved it. Do not assume that saving instructions guarantees every answer.
