Prompting and Workflows — Overview and Exercise Path

This is a learning path. It connects exercises stored in the Exercise Library. Follow the links to do the work, or choose one exercise directly. You do not need to complete every page.

Return here after completing and inspecting useful work. Preserve a method only if it helps you repeat that work; a prompt collection is not the goal.

For your first prompts or guided conversation, use Ask for What You Want or Work Through a Problem with AI. This path is optional continuing practice, not preparation required for other lessons.

Choose the guidance you need

  • Connected Exercise Path — the useful sequence, exercise links and checks between steps.
  • Transfer and Optional Reflection — try the method on a changed case when that helps.
  • Reference at the Point of Need — a worked distinction to use if you get stuck.

Choose the parts that serve your task. Keep private work with you; these lessons are available for community testing.
