Prompting and Workflows — Transfer and Optional Reflection

Use the method again

Use the saved method in a new conversation or another capable assistant. Which facts must you provide again? What changed in the result? Optionally record one condition under which you would stop using this workflow. Carry the correction into its instructions and checks.

Check this changed case

Start with an ordinary request using the same facts and capabilities. Keep the saved method only if its result or repeatability earns the extra setup.

If a correction changes an important fact or behavior, check it again. Reflection is optional: name the change that helped and what you will try next. Keep the useful result; no separate submission or log is required.
