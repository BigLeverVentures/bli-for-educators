Prompting and Workflows — Connected Exercise Path

Begin with evidence and a useful result

Begin with a task you have already completed and inspected, ideally from another exercise. If you have no successful example yet, finish one useful task first. Use Workflow Library Builder to extract the working instructions, required context, output checks and known limits. Do not build a speculative prompt collection just to fill a library.

Keep the method with a successful example

Keep the instructions, required context and meaningful output checks together. Preserve the working version; label changes you have not tried. Use the transfer page when you want to test a new case.

For instruction scope and its difference from changing source facts, see Tell the Assistant How to Help You. A library entry is not automatically an account-wide instruction.

Use only the support you need

Decision Record is useful when the work includes a consequential choice you may revisit. Board of Advisors can challenge a developed decision through several perspectives; it does not supply real experts or create evidence. Negotiation Simulator is separate interactive practice when a negotiation is your task. These options are not a mandatory chain.
