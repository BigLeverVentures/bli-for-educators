# Curriculum release and attribution

Public curriculum release: October 17, 2026. Alpha teaching material; independent
human learning effectiveness has not been established.

Educational direction and original material: Chris Myers and Big Lever Institute.
Curriculum adaptation and drafting: Codex, working with Chris.

This package includes nine AI Basics lessons, 27 exercises, seven four-page
mini-course paths, an optional glossary, curriculum navigation, educator adaptation
resources and two complete fictional teaching examples. Markdown and browser
pages present the same maintained lesson bodies. Full-length courses are outside
this release.

Original educational text, lesson prompts and templates retain [CC BY 4.0](LICENSE.md)
permissions. Verification code has its own [MIT license](tools/LICENSE). External
sources and platforms retain their own terms. Names and logos are not licensed as
another organization's branding.

The [release inventory](release-manifest.json) lists the published pages and file
hashes. The included verification utility checks those files and local links;
it does not establish learning outcomes or future provider availability.

For adaptation instructions, use [the educator guide](educators/adapt-a-lesson.md).
For a proportionate trial in your own setting, use [evaluation and limits](educators/evaluation.md).
